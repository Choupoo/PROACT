## 1. Experiment Update - 21/09/2026

The original detector used three pre-training features:

1. loss,
2. backbone gradient norm,
3. cosine similarity with the past-task gradient direction.

The main purpose of the current experiment is to investigate whether **more fine-grained gradient norms and additional features** can improve detection performance.

## 2. Experimental Setup

### 2.1 Victim Model and Training Setting

The victim model is trained with EWC on Tasks 0--8, and the checkpoint is saved before learning Task 9.

| Component         | Setting         |
| ----------------- | --------------- |
| Dataset           | Split CIFAR-100 |
| Approach          | EWC             |
| Number of tasks   | 10              |
| Incoming task     | Task 9          |
| Epochs            | 20              |
| Batch size        | 16              |
| Lambda            | 500000          |
| Gradient clipping | 100.0           |
| Learning rate     | 0.01            |

### 2.2 Model Inversion for Past Tasks

Model inversion is performed on the pretrained EWC model to obtain reference samples for Tasks 0--8.

| Component                      | Setting                            |
| ------------------------------ | ---------------------------------- |
| Pretrained model               | `runs/victim_seed0/checkpoint.pkl` |
| Inverted tasks                 | Tasks 0--8                         |
| Number of samples              | 128                                |
| Number of inversion iterations | 10000                              |
| Batch regularization           | Enabled                            |

### 2.3 Poisoning Process

| Component                       | Setting             |
| ------------------------------- | ------------------- |
| Attack mode                     | `reckless`          |
| Target task for evaluation      | Task 0              |
| Perturbation budget             | $\ell_\infty = 0.3$ |
| Random seed                     | 0                   |
| Continual learner learning rate | 0.001               |
| Number of attack epochs         | 5000                |
| Distillation source             | Inverted Tasks 0--8 |

### 2.4 Task-9 Dataset Construction

A reproducible and class-stratified Task-9 manifest is constructed.

| Component                    | Setting  |
| ---------------------------- | -------- |
| Training samples per class   | 300      |
| Validation samples per class | 50       |
| Test samples per class       | 50       |
| Number of classes            | 10       |
| Split seed                   | 20260720 |

Clean, poisoned, and norm-matched random-control views derived from the same original image are always assigned to the same data partition.

### 2.5 Detector

The detector is a logistic-regression classifier.

The target clean false-positive rate used for threshold selection is 5%.

In addition to the original three features, I investigated more fine-grained gradient norms and several additional feature types:

* stage-level gradient norms,
* module-level gradient norms,
* parameter-tensor-level gradient norms,
* uncertainty features,
* task-wise gradient similarity statistics,
* activation-based features.

## 3. Validation Results

### 3.1 Baseline vs. Extended Features

On the same validation set:

| Feature Set |  ROC-AUC | Poison TPR @ 5% FPR |
| ----------- | -------: | ------------------: |
| Baseline    | 0.854844 |               44.2% |
| Extended    | 0.973776 |               86.2% |

The ROC-AUC increases from **0.854844 to 0.973776**.

At the same target false-positive rate of 5%, the poison detection rate increases from **44.2% to 86.2%**, corresponding to an improvement of **42 percentage points**.

These results indicate that the additional features substantially improve discrimination on the current validation set.

### 3.2 Comparison of Feature Granularity

| Feature Set | Validation ROC-AUC | Poison TPR @ 5% FPR |
| ----------- | -----------------: | ------------------: |
| Parameters  |            1.0000* |              100.0% |
| All         |            1.0000* |              100.0% |
| Layers      |             0.9998 |              100.0% |
| Extended    |             0.9738 |               86.2% |
| Stages      |             0.9468 |               68.0% |
| Baseline    |             0.8548 |               44.2% |

Overall, **increasing the granularity of gradient-norm features appears highly promising on the current validation set**.

## 4. Layers or Parameters Are More Discriminative

### 4.1 Large Network Stages

When each large ResNet stage is represented by a single gradient norm:

| Stage    | Validation ROC-AUC |
| -------- | -----------------: |
| `layer1` |           0.926420 |
| `layer2` |           0.902452 |
| `layer4` |           0.509672 |

Among these large stages, `layer1` provides the strongest individual discrimination.

In contrast, the overall norm of `layer4` is close to random-ranking performance.

Therefore, the current results do not support a simple conclusion that deeper layers are necessarily more discriminative.

### 4.2 Individual Parameter Tensors

Several individual parameter tensors provide stronger discrimination:

| Parameter                    | Validation ROC-AUC |
| ---------------------------- | -----------------: |
| `layer3.0.conv1.bias`        |           0.949772 |
| `layer3.0.bn1.bias`          |           0.949192 |
| `layer2.0.shortcut.0.weight` |           0.947952 |

These results suggest that some local parameter gradients contain strong discriminative information, while compressing an entire network stage into a single gradient norm may hide this information.

## 5. Contribution of the Extended Features

An ablation analysis was performed by removing individual feature groups from the extended detector.

| Feature Set                     | ROC-AUC | Poison TPR @ 5% FPR |
| ------------------------------- | ------: | ------------------: |
| Extended                        |  0.9738 |               86.2% |
| Without activation features     |  0.9729 |               86.4% |
| Without task-cosine features    |  0.9719 |               83.0% |
| Without uncertainty features    |  0.9626 |               77.4% |
| Without stage-gradient features |  0.9465 |               71.8% |

Removing the **stage-gradient features** reduces the detection rate from 86.2% to 71.8%, a decrease of **14.4 percentage points**.

Removing the **uncertainty features** reduces the detection rate from 86.2% to 77.4%, a decrease of **8.8 percentage points**.

Removing the **task-wise cosine-similarity features** causes a smaller decrease from 86.2% to 83.0%.

In contrast, removing the **activation-based feature** changes the detection rate from 86.2% to 86.4%, while the ROC-AUC changes only slightly. This suggests that activation norms provide little additional information once the other extended features are already included.

Among the feature groups included in the `extended` detector, the current ablation results therefore suggest that **stage-level gradient norms and uncertainty features provide the largest observed contributions**.

Separately, the module-level and parameter-tensor-level gradient norms show very strong discriminative performance on the validation set.

## 6. Fixed Sample-Level Detector: Test Set

Using the frozen `extended` detector and its selected threshold, the test-set performance is:

| Metric                    |    Value |
| ------------------------- | -------: |
| ROC-AUC                   | 0.977832 |
| Average Precision         | 0.974551 |
| Balanced Accuracy         |    0.929 |
| Clean False Positive Rate |     5.6% |
| Poison True Positive Rate |    91.4% |
| Precision                 |   94.23% |
| Recall                    |    91.4% |
| Threshold                 | 0.691961 |

The confusion matrix is:

|        | Predicted Clean | Predicted Poison |
| ------ | --------------: | ---------------: |
| Clean  |             472 |               28 |
| Poison |              43 |              457 |

The detector identifies **457 of 500 poisoned samples**, while incorrectly flagging **28 of 500 clean samples**.

For the norm-matched random-control test set, the positive rate at the same frozen threshold is **12.8%**, compared with **91.4%** for poisoned samples.

This suggests that the detector is not responding solely to perturbation magnitude.

Note that the validation result of 86.2% TPR is measured at a target 5% FPR, whereas the frozen detector achieves 91.4% TPR with a realized clean FPR of 5.6% on the test set.

## 7. Supervised Dataset-Level Detection

The main decision rule is a count-based bound.

Using **500 independent clean calibration images**, 24 sample-level alerts are observed. The one-sided upper confidence bound on the clean sample alert probability is **7.0581%**.

For a batch containing 150 images, the dataset is rejected when at least **18 samples** trigger the sample-level detector.

### 7.1 Dataset-Level Results

| Scenario       | Modified Fraction | Dataset Positive Rate |
| -------------- | ----------------: | --------------------: |
| Poison         |                0% |                  0.0% |
| Poison         |               10% |                 92.6% |
| Poison         |            25.33% |                100.0% |
| Poison         |               50% |                100.0% |
| Poison         |              100% |                100.0% |
| Random control |                0% |                  0.0% |
| Random control |               10% |                  0.2% |
| Random control |            25.33% |                  2.0% |
| Random control |               50% |                 12.9% |
| Random control |              100% |                 69.5% |

At a poisoning rate of 10%, the detector rejects **92.6% of poisoned datasets**, while the corresponding norm-matched random-control rejection rate is only **0.2%**.

For poisoning rates of approximately 25% or higher, all poisoned simulated datasets in the current experiment are detected.

Compared with the previous dataset-level rule, the observed clean-dataset false-positive rate decreases from **19.1% to 0%**.

At the lowest tested poisoning ratio of 10%, the detection rate decreases from **100% to 92.6%**, representing a trade-off between lower false positives and slightly reduced sensitivity at low poisoning ratios.

For poisoning ratios of approximately 25% or higher, the detection rate remains at **100%**.

The random-control alert rates also decrease substantially compared with the previous method:

| Randomly Modified Fraction | Previous Method | Updated Method |
| -------------------------- | --------------: | -------------: |
| 10%                        |           32.6% |           0.2% |
| 25.33%                     |           55.4% |           2.0% |

## 8. Main Conclusions

First, **more fine-grained gradient norms substantially improve discrimination on the current validation set**.

Second, the useful signal is not uniformly distributed across the network. `layer1` provides the strongest discrimination among the coarse stage-level norms, while several individual parameter tensors in `layer2` and `layer3` achieve even higher ROC-AUC values. This suggests that coarse aggregation may hide informative local gradient behavior.

Third, among the feature groups included in the `extended` detector, **stage-level gradient norms and uncertainty features show the largest observed contributions in the current ablation study**. Separately, module-level and parameter-tensor-level gradient norms show very strong validation performance.

Fourth, the frozen `extended` sample-level detector achieves a test ROC-AUC of **0.977832**, a poison TPR of **91.4%**, and a clean false-positive rate of **5.6%**.

Finally, the updated supervised dataset-level aggregation substantially reduces the observed clean-dataset false-positive rate from **19.1% to 0%**. At a 10% poisoning ratio, the detection rate is **92.6%**, while at poisoning ratios of approximately 25% or higher, the observed detection rate remains **100%**.

Overall, the current results support the usefulness of more fine-grained gradient information and show that the updated supervised dataset-level aggregation provides a substantially better false-positive/sensitivity trade-off in the current evaluation.
