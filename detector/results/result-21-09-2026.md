## 1. Experiment Update - 21/09/2026

The original detector used three pre-training features:

1. loss,
2. backbone gradient norm,
3. cosine similarity with the past-task gradient direction.

In this experiment, I mainly looked at whether more fine-grained gradient norms, together with a few additional features, could improve the detector.

---

## 2. Experimental Setup

### 2.1 Victim Model and Training Setting

The victim model is trained with EWC on Tasks 0--8, and the checkpoint is saved before learning Task 9.

| Component         | Setting         |
| ----------------- | --------------- |
| Dataset           | Split CIFAR-100 |
| Approach          | EWC             |
| Number of tasks   | 10              |
| Incoming task     | Task 9          |
| Epochs            | 20              |
| Batch size        | 16              |
| Lambda            | 500000          |
| Gradient clipping | 100.0           |
| Learning rate     | 0.01            |

### 2.2 Model Inversion for Past Tasks

Model inversion is performed on the pretrained EWC model to obtain reference samples for Tasks 0--8.

| Component                      | Setting                            |
| ------------------------------ | ---------------------------------- |
| Pretrained model               | `runs/victim_seed0/checkpoint.pkl` |
| Inverted tasks                 | Tasks 0--8                         |
| Number of samples              | 128                                |
| Number of inversion iterations | 10000                              |
| Batch regularization           | Enabled                            |

### 2.3 Poisoning Process

| Component                       | Setting             |
| ------------------------------- | ------------------- |
| Attack mode                     | `reckless`          |
| Target task for evaluation      | Task 0              |
| Perturbation budget             | $\ell_\infty = 0.3$ |
| Random seed                     | 0                   |
| Continual learner learning rate | 0.001               |
| Number of attack epochs         | 5000                |
| Distillation source             | Inverted Tasks 0--8 |

### 2.4 Task-9 Dataset Construction

A reproducible and class-stratified Task-9 manifest is used.

| Component                    | Setting  |
| ---------------------------- | -------- |
| Training samples per class   | 300      |
| Validation samples per class | 50       |
| Test samples per class       | 50       |
| Number of classes            | 10       |
| Split seed                   | 20260720 |

Clean, poisoned, and norm-matched random-control versions of the same original image are always kept in the same split.

### 2.5 Detector

The detector is a logistic-regression classifier. The target clean false-positive rate for threshold selection is 5%.

Besides the original three features, I tested:

* stage-level gradient norms,
* module-level gradient norms,
* parameter-tensor-level gradient norms,
* uncertainty features,
* task-wise gradient similarity statistics,
* activation-based features.

## 3. Validation Results

### 3.1 Baseline vs. Extended Features

On the same validation set:

| Feature Set |  ROC-AUC | Poison TPR @ 5% FPR |
| ----------- | -------: | ------------------: |
| Baseline    | 0.854844 |               44.2% |
| Extended    | 0.973776 |               86.2% |

With the extended feature set, ROC-AUC increases from 0.854844 to 0.973776. At a 5% target FPR, poison TPR increases from 44.2% to 86.2%.

This is a 42 percentage-point improvement in TPR over the original three-feature baseline.

### 3.2 Comparison of Feature Granularity

| Feature Set                  | Validation ROC-AUC | Poison TPR @ 5% FPR |
| ---------------------------- | -----------------: | ------------------: |
| Parameter-tensor-level norms |            1.0000* |              100.0% |
| All investigated features    |            1.0000* |              100.0% |
| Module-level norms           |             0.9998 |              100.0% |
| Extended                     |             0.9738 |               86.2% |
| Stage-level norms            |             0.9468 |               68.0% |
| Baseline                     |             0.8548 |               44.2% |

* Values shown as `1.0000` are rounded and are not necessarily exactly equal to 1. These are validation results and have not yet been independently confirmed.

Module-level and parameter-tensor-level norms perform best on this validation set, but I would like to confirm this in a new frozen experiment before drawing a stronger conclusion.

## 4. Layers or Parameters Are More Discriminative

### 4.1 Large Network Stages

When each large ResNet stage is represented by one gradient norm:

| Stage    | Validation ROC-AUC |
| -------- | -----------------: |
| `layer1` |           0.926420 |
| `layer2` |           0.902452 |
| `layer4` |           0.509672 |

`layer1` performs best among the large stages. `layer4` is close to random ranking.

There is no clear pattern showing that deeper stages are always more useful.

### 4.2 Individual Parameter Tensors

Some individual parameter tensors are more discriminative than the coarse stage-level summaries:

| Parameter                    | Validation ROC-AUC |
| ---------------------------- | -----------------: |
| `layer3.0.conv1.bias`        |           0.949772 |
| `layer3.0.bn1.bias`          |           0.949192 |
| `layer2.0.shortcut.0.weight` |           0.947952 |

A possible explanation is that useful local gradient information is partly lost when all parameters in a large stage are compressed into one norm. I treat this as an interpretation of the current results rather than a confirmed mechanism.

## 5. Contribution of the Extended Features

I also ran an ablation study by removing one feature group at a time from the `extended` detector.

| Feature Set                     | ROC-AUC | Poison TPR @ 5% FPR |
| ------------------------------- | ------: | ------------------: |
| Extended                        |  0.9738 |               86.2% |
| Without activation features     |  0.9729 |               86.4% |
| Without task-cosine features    |  0.9719 |               83.0% |
| Without uncertainty features    |  0.9626 |               77.4% |
| Without stage-gradient features |  0.9465 |               71.8% |

Removing the stage-gradient features has the largest effect on TPR: 86.2% to 71.8%.

Without the uncertainty features, TPR falls to 77.4%. Removing the task-wise cosine features gives 83.0%.

The activation feature makes little difference in the full combination. Without it, TPR changes from 86.2% to 86.4%, with only a small change in ROC-AUC.

For the current `extended` feature set, stage-level gradient norms and uncertainty features have the clearest contribution. Module-level and parameter-tensor-level norms were evaluated separately and also perform well on validation.

## 6. Fixed Sample-Level Detector: Test Set

Using the frozen `extended` detector and its selected threshold:

| Metric                    |    Value |
| ------------------------- | -------: |
| ROC-AUC                   | 0.977832 |
| Average Precision         | 0.974551 |
| Balanced Accuracy         |    0.929 |
| Clean False Positive Rate |     5.6% |
| Poison True Positive Rate |    91.4% |
| Precision                 |   94.23% |
| Recall                    |    91.4% |
| Threshold                 | 0.691961 |

The confusion matrix is:

|        | Predicted Clean | Predicted Poison |
| ------ | --------------: | ---------------: |
| Clean  |             472 |               28 |
| Poison |              43 |              457 |

The detector identifies 457 of 500 poisoned samples and incorrectly flags 28 of 500 clean samples.

For the norm-matched random-control test set, 12.8% of samples are above the same threshold, compared with 91.4% for poisoned samples. The gap is large enough that perturbation magnitude alone does not explain the detector response.

The validation and test TPRs are not measured at exactly the same operating point. The validation result is 86.2% TPR at a target 5% FPR, while the realized test FPR is 5.6%, with a TPR of 91.4%.

There is also an important limitation. The extended feature design was developed after looking at results from the previous experiment, and the same underlying test images are reused. I therefore treat this as a diagnostic re-evaluation rather than an independent confirmation.

## 7. Supervised Dataset-Level Detection

I then use the sample-level detector to make a dataset-level decision.

The rule is count-based. Among 500 independent clean calibration images, 24 are flagged by the sample-level detector. The one-sided upper confidence bound on the clean sample alert probability is 7.0581%.

For a batch of 150 images, the dataset is rejected if at least 18 images are flagged.

### 7.1 Dataset-Level Results

| Scenario       | Modified Fraction | Dataset Positive Rate |
| -------------- | ----------------: | --------------------: |
| Poison         |                0% |                  0.0% |
| Poison         |               10% |                 92.6% |
| Poison         |            25.33% |                100.0% |
| Poison         |               50% |                100.0% |
| Poison         |              100% |                100.0% |
| Random control |                0% |                  0.0% |
| Random control |               10% |                  0.2% |
| Random control |            25.33% |                  2.0% |
| Random control |               50% |                 12.9% |
| Random control |              100% |                 69.5% |

At 10% poisoning, 92.6% of the simulated poisoned datasets are rejected. At the same modification rate, the rejection rate for the norm-matched random control is 0.2%.

All simulated poisoned datasets are detected at the tested poisoning fractions of 25.33%, 50%, and 100%.

Compared with the previous dataset-level rule, the observed clean-dataset false-positive rate drops from 19.1% to 0%. The main cost is at 10% poisoning, where TPR drops from 100% to 92.6%.

### 7.2 Random-Control Comparison

| Randomly Modified Fraction | Previous Method | Updated Method |
| -------------------------- | --------------: | -------------: |
| 10%                        |           32.6% |           0.2% |
| 25.33%                     |           55.4% |           2.0% |
| 50%                        |           84.3% |          12.9% |
| 100%                       |           99.1% |          69.5% |

The difference is largest at low modification rates. With 10% modified samples, poisoning detection is 92.6%, while the random-control rejection rate is 0.2%.

The separation becomes weaker when most samples are perturbed. With 100% random perturbation, 69.5% of the simulated datasets are still rejected. The current detector therefore does not reliably distinguish arbitrary perturbations from poisoning in every setting.

There are two statistical limitations here. The calibration argument assumes that the clean calibration images and future clean samples are independent and have the same alert probability.

Also, although 1,000 simulated datasets are generated for each condition, they reuse images from a finite test pool. They should not be treated as 1,000 independent experimental runs.

The observed 0% clean false-positive rate is therefore specific to this evaluation and does not imply that the true false-positive probability is zero.

---

## 8. Main Conclusions

The main improvement comes from using more detailed gradient information. On validation, the baseline reaches 0.8548 ROC-AUC and 44.2% TPR at 5% FPR, while the extended detector reaches 0.9738 ROC-AUC and 86.2% TPR.

The layer analysis suggests that useful information is local rather than simply concentrated in deeper stages. `layer1` performs best at the stage level, while several individual tensors in `layer2` and `layer3` perform even better. In the ablation study, stage-level gradient norms and uncertainty features have the largest effect within the `extended` feature set.

At the dataset level, the new count-based rule reduces the observed clean false-positive rate from 19.1% to 0%. The main trade-off is at 10% poisoning, where TPR decreases from 100% to 92.6%. Detection remains at 100% for the tested poisoning fractions of 25.33%, 50%, and 100%.

The next step is to freeze the current detector and thresholds and repeat the evaluation with new model seeds, task orders, attack seeds, and poisoning settings.
