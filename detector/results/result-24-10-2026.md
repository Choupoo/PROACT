# Experiment update — 24/10/2026

The registered CIFAR-100 runs have finished for all five methods and seeds 6, 7 and 8. This extends the 18/10 report with the third MAS and RWalk seeds and all AFEC-EWC and ANCL-EWC runs. Each method/seed has four BrainWash tests, nine supervised feature variants, Rank/MMD results and full-task forgetting controls.

EWC remains the most consistent case. At budget 0.3, all three seeds detect every reckless simulation containing 8 poisoned images out of 150; cautious detection is 95–100%. None of their clean simulations alerts. The lower budget remains difficult, especially in seed 7. MAS improves in seed 8 but still misses many attacks. RWalk's third seed reduces the false-alert rate, although it remains above the intended level.

Tensor gradient norms retain most of the ranking information. The other four features help in some weaker-attack cases, so the ablations do not support removing them in every setting. Rank produces fewer clean alerts than MMD but remains unreliable at low poisoning fractions and sometimes misses fully poisoned datasets.

## 2. Experimental Setup

### 2.1 Completed Runs and Task Roles

| Component | Setting |
| --- | --- |
| Benchmark | Split CIFAR-100, ten tasks with ten classes each; fixed class order |
| CL implementations | EWC, MAS, RWalk, AFEC-EWC and ANCL-EWC |
| Completed seeds | 6, 7 and 8 for each implementation |
| Source task | Task 1: fit StandardScaler and logistic regression |
| Calibration data | Clean validation and reserve images from Tasks 1 and 4 |
| Development check | Task 4 test split; diagnostics only |
| Final evaluation | Task 9, without detector fitting, recalibration or feature selection |
| Target attacks | Reckless/cautious BrainWash × L-infinity budgets 0.1/0.3 |
| Dataset simulations | 150 distinct originals per simulation; 100 simulations per fraction |
| Ablations | Nine fitted variants, including the full detector |
| Unsupervised comparison | Rank and historical-reference MMD |

Tasks are numbered from zero. I extract features before the defender learns the incoming task. The Task 9 defender has learned Tasks 0–8. The seeds change training and attack generation while retaining the same CIFAR image pool and class order.

Each method/seed has its own fitted detector. Task 1 supplies 3,000 training originals, each represented by a clean negative and its reckless BrainWash version at budget 0.3 as a positive. This gives 6,000 feature rows from 3,000 originals, not 6,000 independent images. Random perturbations are used only for evaluation.

Each task has 3,000 training, 500 validation, 1,000 reserve and 500 test originals. All views of one original stay in the same split. Task 9's training, validation and reserve splits do not fit or calibrate the detector. Its sample evaluation uses 500 clean and 500 poisoned test views, with another 500 random-control views scored separately.

I fixed `history_mad` after the seed 5 pilot, before these runs. Task 4 test results check the fixed rule; they do not select another one. The source-quantile and historical-quantile rules remain frozen comparisons. The four target attacks share the same fitted full detector within each method/seed, rather than being used to train four separate full detectors.

### 2.2 Training and Attacks

| Component | Setting |
| --- | --- |
| Victim training | 100 epochs per learned task; learning rate 0.01, batch size 16 |
| Regularisation coefficients | EWC: 500,000; MAS: 10; RWalk: 1 |
| Auxiliary-method coefficients | AFEC-EWC and ANCL-EWC: lambda 500,000, lambda_emp 100 |
| Historical inversion | 2,000 iterations; 128 samples per historical task |
| BrainWash optimisation | 5,000 epochs; n_iters = 1 |
| Attack generation | Historical inversion samples; real = false, reverse = false |
| Cautious setting | w_cur = 1.0 |
| Source/calibration attack | Reckless BrainWash, L-infinity budget 0.3 |
| Target attacks | Reckless and cautious BrainWash, L-infinity budgets 0.1 and 0.3 |
| Random control | Uniform perturbations at the same L-infinity budget, followed by image clamping |

These are four configurations of BrainWash, not four attack families. The attacker uses the incoming-task training originals, including those later assigned to the detector test split. They are held out from fitting the detector, not from attack optimisation. One artifact is generated per task/attack configuration, not per simulated dataset.

### 2.3 Features

| Supervised feature | Dimensions | Meaning |
| --- | --- | --- |
| Parameter-tensor gradient norms | 80 | L2 norm of the loss gradient for each backbone weight or bias tensor |
| Entropy | 1 | Spread of the head's predicted class probabilities |
| Confidence | 1 | Largest predicted probability |
| Margin | 1 | Difference between the two largest probabilities |
| Activation norm | 1 | L2 norm of the representation entering the incoming head |

The full detector has 84 inputs. Each tensor feature is the Euclidean norm over all entries of that tensor's gradient, not a separate feature for each scalar weight. Gradients use the model's predicted class as the loss target. True-class probability, loss and historical-gradient cosine features are not classifier inputs. Image-class labels construct the offline benchmark and stratified splits; extraction and scoring do not use them.

The incoming head is initialised with a fixed seed and is untrained on that task. Its probabilities are probe responses, not calibrated estimates of classification correctness. The model remains in evaluation mode, without parameter updates or changes to BatchNorm state.

## 3. Frozen Thresholds

For each calibration task, I calculate a clean validation quantile and a robust cutoff from the median plus three scaled median absolute deviations of clipped score logits. I retain the larger cutoff, then take the maximum across Tasks 1 and 4. The scale factor for MAD is 1.4826.

After fixing the sample cutoff, I count alerts in each task's separate reserve-clean images. A one-sided Clopper–Pearson upper bound estimates the clean sample-alert probability. The larger historical bound sets the smallest count whose binomial upper tail is at most 0.025. The estimation budget is also 0.025. A 150-image dataset alerts at or above that count.

## 7. Unsupervised Results

### 7.1 Rank and MMD Setup

Neither test uses labelled clean/poison detector-training examples or known-clean Task 9 calibration images. They use ten per-image descriptors: the global backbone gradient norm, five stage norms, entropy, confidence, margin and activation norm. Gradients use the predicted class. Each historical task supplies 128 inversion images, giving 1,152 reference images from Tasks 0–8. Reference and incoming images use the same frozen Task 9 defender and incoming head.

Rank compares whole-dataset dependence profiles, not individual poison predictions. It calculates Kendall tau-a for feature pairs. Historical references alone retain pairs whose jackknife pseudovalue variance exceeds 10^-12 in every task. For each historical comparison, the statistic is the largest absolute correlation difference over those pairs.

I approximate its variation with 499 Gaussian multiplier draws from centred jackknife pseudovalues. Image weights are shared across feature pairs within a draw; incoming and reference weights are independent. The approximate p-value is (1 + number of bootstrap statistics at least as large as the observed statistic) / 500. The draws do not create new image datasets.

Rank takes the maximum p-value over historical tasks and alerts only if all nine comparisons reject at 0.05. Failure to reject one comparison does not prove that the incoming dataset is clean. The approximation relies on independence and nondegenerate variation, which inversion samples need not satisfy.

The original MMD compares descriptor distributions through a random-Fourier approximation to an RBF kernel and a permutation test. Rank and MMD use identical bags within their evaluator. The supervised evaluator has a separate deterministic sequence, so a supervised bag index is not paired with the same unsupervised bag index.
